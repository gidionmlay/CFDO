# Complexity, risks, and open questions

## Highest-iteration areas

1. **Hero media and type:** The reference depends on a highly specific crop and enormous type. CFDO needs its own imagery and line breaks, so responsive composition will require real browser iteration.
2. **Balancing mission with consultancy:** The brief asks for both; the transition must clarify the relationship without making one appear incidental.
3. **Programme grid:** Five unequal subjects in an editorial layout create mobile order and image ratio challenges.
4. **Story and project proof:** Real records and approved media determine whether these sections can launch. Placeholders can preserve geometry in development but must not imply real impact.
5. **Menu, accordion, and optional sliders:** Accessibility, keyboard behavior, and focus need focused checks when implemented.
6. **News/CMS:** Schema, publication flow, and article routes are not specified yet.

## Unknowns that remain unknown

- Exact source motion easing, duration, scroll-library use, hover transformations, smooth-scroll behavior, and reduced-motion behavior.
- Source design token values outside the browser samples; exact underlying grid and CSS breakpoints.
- Whether some source media moves continuously with scroll. The sampled states do not establish parallax.
- CFDO logo, finalized brand palette/fonts, approved photographs, stories, project records, impact figures, testimonials, partner logos, news, and consent status.
- CFDO donation flow, form endpoints, CRM, CMS choice, hosting, and route inventory beyond the brief.

## Working assumptions

- English first, Swahili readiness later, as stated in the brief.
- A responsive homepage is the first implementation target; inner pages are future work unless separately authorized.
- Source-specific visuals and copy are replaced with original or user-provided material.
- The next authorized implementation starts with foundation/header or the first section explicitly selected by the user, then stops after that section's validation as `prompt.md` requires.
